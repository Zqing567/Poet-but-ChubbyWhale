## 仓库状态

**迁移整理阶段（尚未宣称完整再现公开成片）。** 已发布或即将发布的文字与代码并不意味着私人素材、歌声、BGM、配音样本、社区表情包可随意公开复制。最终可以公开的媒体将按逐项来源、授权与实际依赖审查进入本仓库。
