# 大肥鱼的创作工坊

这里放大肥鱼的作品、素材与制作手记。我们把AI工具生成的图片和声音，慢慢改成有故事、有笑点的作品，也把好用的方法和走过的弯路留下来。每部作品有自己的页面，看作品、找素材、学做法都可以直接进入。

## 第一部：《将进 token》

小小的大肥鱼站上显卡海崖吟诗，转头又邀Claude、GPT来一场“曲水流饭”。十二句AI梗诗，两幅古风主画，87.1秒。

## 这次留下了哪些做法？

- 配音先锁音色，再分段试听；保留好的版本，只重做读不顺的句子。
- 生图先把空间画对：海崖要有落差，曲水要能串联人物，再修身份、动作和细节。
- 主画保持稳定，诗句累积、金币和心理小剧场各自叠加；片尾留几秒，动作与音乐继续。

教程保留真实候选、作者反馈、完整脱敏Prompt和代码入口，也明确哪些实验最后没用。后续作品会继续增加独立项目页。
