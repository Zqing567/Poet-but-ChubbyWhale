# 代码许可证等待作者确认

作者明确提出把大肥鱼工程开源，并已创建公开仓库。但源项目 editor/package.json 写明 `UNLICENSED`，意味着**在选定正式许可证之前，仓库公开可读不等于代码已获自由再使用许可**。

请作者在发布许可证前选择：MIT（简短宽松）、Apache-2.0（额外专利许可条款）、GPLv3（衍生代码分发有保持同许可证的义务）等，必要时了解其与项目依赖及自身目标的匹配。许可证一旦授予已获得许可的版本，不应假设随时可以撤回既有授权。

选择后：
1. 给自己有权许可的源代码添加 `LICENSE` 文件，更新 package.json 的 license；
2. 明确排除不能再许可的 BGM、歌曲/声音参考、第三方角色/表情/字体等；这些需要各自授权；
3. 添加 THIRD_PARTY_NOTICES/ATTRIBUTIONS 清单；
4. 在 README 中明确“本仓库代码、AI 辅助生成场景、素材”的不同许可；
5. 重新完成公开下载/再分发测试，不要用 blanket 许可覆盖版权未明作品。

当前 repo 暂时不猜测作者希望采用哪一种开源许可。
