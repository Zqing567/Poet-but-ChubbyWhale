# 开源素材与隐私边界（必须先读）

## 当前事实

源头 `AI-CookUp` 的 `codex/bigfish-v3-visuals`@0357d1b 属于**私有仓库**；本仓库是**公开仓库**。原始工程约 760 个文件、396.5 MB。其中包含最终视频、个人克隆音色的已渲染语音、商业/平台歌曲参考、经典社区角色表情、字体和多个历史生成版本。

**不能因为自己完成过视频，就推断每个源素材都有“开放再分发许可证”。** 原记录明确标记多张表情包和 Eutopia / Let Me Go 相关录音的权利待核。公开发布成片与向所有 GitHub 用户分发可提取的单独音轨、原始图片，是不同使用行为。

## 资产等级

| 等级 | 判据 | 默认操作 |
| --- | --- | --- |
| A：已获确认可再分发 | 来源明确、许可证/授权记录存档、符合使用条件 | 可进入公开 assets；附作者/许可及必要声明 |
| B：原创/AI 辅助生成待核 | 有自己制作记录，但需核对服务条件、引用的角色/图样来源 | 暂不自动公开；逐项确定来源和授权 |
| C：只限研究/成片使用 | 第三方歌曲、原唱片段、社区动图、克隆音色样本、演唱人声等 | 公共仓库只保留来源与功能说明；不上传源文件 |
| D：隐私或密钥 | .local.md、.env、Authorization、TTS key、个人绝对路径中泄密部分 | 永不提交；必要时轮换误泄露凭证 |

**不因扩展名作授权判定**：png 未必是原创，MP4 未必无权利。默认所有二进制资产 pending；必须有人逐项审核后通过 manifest 选择公开。

## 视频和音乐

- 不自动把 Eutopia 竹笛音源、Let Me Go 原曲或其人声分离样本、克隆音色 WAV/MP3、第三方梗图加入新仓库。
- 若有合法公开成片，建议以官方 B 站投稿链接作为观看入口；不等于可拆出所有组成轨道。
- 文字说明可以描述采用了哪种音频处理流程，但不公开未授权样本。
- 公开人声语料应额外核实名人/角色声音与训练服务条款。

## 字体

Remotion 工程使用 Fusion Pixel、Cubic 11、霞鹜文楷等字体。**明确区分字体源文件和所对应的许可证**，可以保存官方链接、版本和许可文本，是否将字体二进制纳入发布按各自许可条款决定；不得将所有字体一律视为公共领域。

## 代码许可

迁移前原项目 editor/package.json 标注 `UNLICENSED`。新仓库尚未获作者明确选定 MIT、Apache-2.0、GPL 等许可证。**目前公开可读不等于符合 OSI 意义上的开源许可证**。请作者确定代码许可后添加 LICENSE，并检查相关第三方依赖及引用代码，不要擅自给他人图片和音乐套同一许可证。

## 每个公开资产需要的登记

`asset_id`、源项目相对路径、作者/原始来源、用途、来源参考、许可/书面批准、改编说明、SHA-256、关联故事节点、归档日期、审核者、审核证据。缺任何关键字段时状态为 pending，不允许导出到公共仓库。

## 密钥扫描

发布之前至少搜索：API_KEY、sk-、Bearer、Authorization、.env、.local、TTS voice_id、令牌查询参数、个人绝对路径，完成 git diff / 二进制大小 / git history 检查。隐私文件即使本次删除过，只要曾出现在提交历史，也可能留在历史中。
