## 三个基本原则

**从实际成片倒推**：正式工程的代码、渲染器、经核验的媒体，与作者确认过的两幕结构优先于早期 Plan。

**把做法与经验并排记录**：输入是什么、具体工具/参数、输出是什么、失败发生在哪里、如何验收，以后才能快速复用。

**一次作品只有一个正式版本**：历史版本不删除出处，但不把 v06/v07/v09 全部放到 root 冒充不同成片。
7. [七项经验与证据](LESSONS_WITH_EVIDENCE.md)：角色、海崖、曲水、朗诵、文字、动画、合成的可复用步骤。
8. [实际整理报告](../../../reports/00_baseline.md)与[素材清点](../../../reports/01_inventory.md)。
