# 影片结构：从十二句诗到两幕与贯穿叠加层

正式影片 87.1 秒。不要把原来审稿预览 94.67 秒或 v07/v09 长度混作投稿定稿。原 Remotion 的具体语音与字幕时间以编辑工程 `src/captions.json`、`src/upper-half.json` 和选定最终混音为准。由于成片末尾附加 3 秒动作/BGM，完整影片从叙事上分为两个主要场景加一段尾声。

## 为什么是两幕，不是逐句换画

整片以“传统水墨画气质与现代 AI 梗”的违和形成趣味。SC01 通过小小诗人鱼与海崖、鲸群、金属 GPU 的冲突建立世界观；SC02 通过古代文人曲水流觞改成白饭碗，与一群 AI 娘雅集形成喜剧高潮。频繁换背景会损失画面统一性和文字可读性。每句变化主要靠**独立叠加层**而不是第三到第十四幕。

## 叙事与技术不要混为一谈

“配音”跨两幕，不应在 SC01/SC02 重复维护两份；“字幕”以 Lxx 映射两幕但共享状态机；“经典鱼表情包”从原画入场、短暂展示和退出，独立于两张静态背景；音乐也不是一个场景文件。

相关代码：`editor/src/UpperHalf.tsx`、`LowerHalf.tsx`、`FullReview.tsx`、`CaptionStudy.tsx`、`cue-model.ts`、`captions.json`、`upper-half.json`。详见制作模块文档。

## 人物与情感线

主角是“自认为盛唐诗仙的蓝色大肥鱼”，高姿态吟诗，同时端盆等饭。L01 起兴、L04 得意高昂、L06 邀歌、L07 收势、L09 进入歌曲、L12 狂呼。角色“内在身份性格情绪”和“外观姿态服装动作”必须相互对应。这来自作者 Canvas 特别指出的视觉/人物/场景协调关系。
