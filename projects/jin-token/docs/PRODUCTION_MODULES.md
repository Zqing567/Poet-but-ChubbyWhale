## M00｜诗文与时间轴

保留原文与朗读文本的双层管理。12 句各有稳定 Lxx 标识、场景 A/B、起止帧及可分行显示的 rows。时间不平均分配，来自实际 TTS 朗读和歌曲剪辑。不要把某轮旧版“七秒一句审稿占位节奏”当成正式片节奏。将来若替换声音，需重新校准字幕和意象事件而非只换 mp3。

## M10｜场景与角色

**SC01** 的真正困难是“高海崖俯瞰开阔海面”而不是“近水远山”的传统河岸构图；人物需要小，海天需要宽，鲸可以有夸张辨识，GPU 岩石仅局部点缀。选图经过“偏工笔→淡彩写意→镜头推进→突出虎鲸→GPU 海崖”多轮评审。最后的 GPU 崖面不是把商品显卡照片简单贴上。

**SC02** 的真正困难是曲水流觞不是大湖边聚会。作者参考《兰亭修禊图》与手绘水流，选择“左侧主角、沿曲水分散的 AI 娘、右侧留诗文”。白饭碗顺水漂流形成笑点，人物必须“因水而组织”。主角一手端白饭、一手宴请，Claude/GPT 最近、其他听众更远。该故事画面与视觉选择，不能从空白模型 prompt 反推为真实历史古画。

视觉源与最终选择在旧库 production/v3/editor/public/upper-half、lower-half；本公开仓库只按有权利再分发的素材逐项加入。

## M20｜声音

三个可分离模块：BGM（Eutopia 竹笛版）、音效（金币入盆）、朗诵与歌唱。已选声音素材曾尝试复刻 Let Me Go，后转向带有“派蒙”声线参考的声音方向，再通过千问 TTS 的分段指令、发音热修、导演谱、朗读时长编辑、试听与拼接改善连贯性。**这是项目使用路径描述，不表示有权公开上传该参考声线或歌曲源文件。**

关键经验：把“音色确定”和“韵律表演正确”拆成两个问题；导演谱按 Lxx 标重音、停连、收势、延音，接口能力由实际 provider 探针确认；自动质检剔除漏字、过长静音、削波，艺术听感仍需试听。配音与歌曲切换应建立自然声学接点。

## M30｜文字

初版右侧文字每句覆盖前句；V2 一次展示全部；最终要求为**一句一句进入、已读句保留、一个场景末完整呈现本场景诗文**。试用 Fusion Pixel 等字体以突出 AI 味。主要对比 CSS/Remotion 动画的入场、淡入、擦写、像素字符渐现；关键是先把七句末态排下再设计动态，不能为了形式牺牲中文和英文混排可读性。

## M40｜效果叠加

分为三类，避免把所有都称为“动画”：
- **符号动画**：金币轨迹、GPU 岩纹和光效，可以程序生成；不要强拉人物骨骼。
- **画中画/心理气泡**：经典鱼的表情包与诗仙背景形成反差。Layer 独立控制，不遮挡字幕。
- **人物动态**：原有表情 GIF 或经过抠图后的透明 WebM 叠层。复杂自然动作若程序拉伸畸形，优先换真实素材或 Gemini 镜头，而非靠扭曲位图补洞。

M40 贯穿 SC01/SC02，但不应直接写死成“场景 A/B 各有一套特效引擎”。

## M50｜合成

`FullReview.tsx` 统一引入 `UpperHalf`、`LowerHalf` 与整片音轨，使用 `upper-half.json` 中场景切点和原声路径。最初有明显突兀转场，后改用淡墨过渡与图层变化。字幕和 BGM 同步由同一帧基准控制。不要把声音单独导出后又在多个场景重复播放造成音频叠加。

## M60｜发布

正式 4K 版直接由 Remotion 工程以 scale=3 渲染，H.264、AAC 48kHz，不是把旧 720P 影片拉大。源原画分辨率未必 4K，宣传时不能声称背景细节原生 4K。最终长 87.1 秒，含 3 秒尾声；确认了完整解码、音频相关性、尾部动态和音乐淡出；详见 release 文档。

## 复用边界

未来“新的大肥鱼吟诗”可以沿用 M00/M30/M50/M60；角色资产/曲水背景/歌词梗图等是本片特定内容，需替换素材。跨多部验证后再抽象 shared 模块。
## 定稿核对修正（2026-10-26）

- 正式GPU海崖由静态PNG承载；TokenRain是程序金币，不能把候选GPU发光说成最终采用。
- FullReview转场为米白覆盖层透明度插值；不是已经完成的海水变溪水流体效果。
- 正式JinToken-Final入口统一2613帧及尾声混音；V3-Review为旧工作坊，导出器不再依赖覆盖旧入口片长。
- 七项具体复盘、源码和证据边界见[LESSONS_WITH_EVIDENCE](LESSONS_WITH_EVIDENCE.md)。
