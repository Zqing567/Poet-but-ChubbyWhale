# 历史版本与失败实验

这里只保留按**决策主题**整理后的索引，不同步所有尝试版 MP4、临时网页、API 测试缓存和一大堆时间戳文件。

| 主题 | 早期问题 | 最终方向 |
| --- | --- | --- |
| A 场景地貌 | 近水远山像河岸、角色/显卡过大 | 真海崖、海天留白、小鱼、鲸群、适度 GPU |
| B 场景结构 | 一大片湖、人物随意排坐 | 兰亭修禊式曲水、漂饭碗、角色因水而组织 |
| 美术 | 太工笔/太像游戏海报 | 写意淡彩，允许原皮与古画轻微反差 |
| 字幕 | 每句替换/一次铺满 | 逐句进入、读毕留存，五/七句成篇 |
| 声音 | 克隆了音色但不会吟诗 | 导演谱、按段生成、发音词典、A/B 选版、后期拼接 |
| 动效 | 生硬转场、强拉手臂变形 | 独立轻动画层、必要时交视频生成，水墨淡化转场 |
| 发布 | 旧审阅占位样片与正式版混杂 | 明确 4K 87.1 秒正式版本，原片与封面独立归档 |

每一条正式结论都要有对应最终源码/素材/验收记录。源仓库中的 V0、V2、v06、v07、v09、v11 和最终 4K 在时间线上均有用途，但不需要将其所有二进制历史镜像复刻到公共项目。

未来如某失败实验是教程重点，可添加一个去隐私、无版权风险的前后对照小样及具体复现步骤，注明它**不是正式成片的一部分**。
