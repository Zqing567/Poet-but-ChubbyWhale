# 《将进 token》是怎么做出来的？

大肥鱼站在显卡海崖上吟诗，铁盆等着token落下来；念到兴头上，又在曲水边邀请朋友吃饭。十二句诗、两幕古风画面，加上左上角藏不住的心理活动，组成了这支87.1秒的视频。

## 制作顺序

1. **先写能表演的诗。** 前半段望海吟诗，后半段邀朋友吃饭，豪迈、得意和收势要有变化。
2. **画对角色与场景。** 海崖不能像河岸，曲水不能像湖边合影；大肥鱼保持Q版，右侧提前留诗句空间。
3. **选音色，调朗诵。** 用 `qwen-audio-3.1-tts-flash` 分段试音，按导演谱修改停顿、重音和英文读法。
4. **分层加文字和笑点。** 诗句读过以后留下，金币用代码下落，心理气泡按诗意切换静图和透明动态。
5. **统一时间线并导出。** React与Remotion按帧合成，输出4K/30fps；片尾再留3秒，动作继续、音乐淡出。
