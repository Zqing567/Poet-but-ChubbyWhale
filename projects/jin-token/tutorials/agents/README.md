# 把教程交给Agent时，先准备什么？

先选一个任务，不要把全套教程一次丢进去就要求复刻整片。

| 任务 | 先准备 | Agent做什么 | 你来判断 |
| --- | --- | --- | --- |
| [朗诵](../01_voice.md#如果你也打算让-agent-复刻) | 合法音色参考或可用音色、模型/接口、本机密钥、台词 | 小批生成、保存参数、整理A/B、拼接干声 | 哪版表演更好，重音/英文读法是否合适 |
| [角色](02_character.md) | 合法身份参考、服装方向、比例、可用生图工具 | 整理身份锚点、逐轮换装、三视图、透明通道检查 | 是否像原角色、服装是否合意 |
| [海崖](03_cliff.md) | 角色参考、景观/画风参考、画幅、字幕留白区 | 小批候选、局部修改、图片与Prompt对照 | 地理、镜头、鲸与硬件密度 |

先让Agent报告能使用的工具和需要的素材。没有生图或语音接口，就先整理Prompt与文件清单，不把计划写成已生成。每轮都另存原件和修改说明，别覆盖好版本；音频密钥、实际音色ID和未经授权的参考不上传Git。

上面的任务文件是本轮编写的跟做说明。历史生图/语音请求另行保存，不能把二者混成“当年原始Prompt”。
