# 《将进 token》制作教程

从想法到导出，共七篇。每篇先讲实际怎么做，再给跟做方法与可复制的Agent任务。配音沿用作者修订稿，角色与海崖沿用已认可的样章写法。

| 教程 | 能学到什么 |
| --- | --- |
| [01 朗诵与配音](01_voice.md) | 固定音色、分组试音、导演谱、停连与最后选版 |
| [02 角色形象与一致性](02_character.md) | 参考分工、古风换装、透明边缘、三视图与保守修复 |
| [03 显卡海崖与鲸群](03_cliff.md) | 从水岸到高崖，调整镜头、鲸与GPU局部材质 |
| [04 曲水流饭](04_garden.md) | 双岸窄溪、主宾关系、Q版站姿、饭碗与多角色身份 |
| [05 诗句与字幕](05_captions.md) | 像素字体、末态分行、逐句累积与音频定时 |
| [06 心理活动与动效](06_motion.md) | 纸云、透明WebM、循环、金币轨迹与片尾留白 |
| [07 合成与导出](07_compositing.md) | 统一时间线、转场、演示与本地素材、4K及检查 |

想先做出一点东西，可以试配音篇的G1 A/B；想研究画面，从角色、海崖或曲水任选一篇。已经有素材、想交给Agent，就从[准备材料与任务](agents/README.md)开始。运行工程前先看合成篇的两种素材路径。

[图片与提示词入口](MATERIALS.md)集中列出可用文件；[图片阶段说明](IMAGE_NOTES.md)区分真实原件、裁切、当前重绘与新示意。旧的[制作复盘](../docs/EXPERIENCE.md)和[技术资料](../docs/README.md)继续保留，供需要细节的读者查阅。
