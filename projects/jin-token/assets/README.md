# 图片、媒体与运行素材

公开图片和完整Prompt从[素材入口](../tutorials/MATERIALS.md)进入。角色、海崖、心理图与教程裁切均附[逐图说明](../tutorials/IMAGE_NOTES.md)；本目录保留许可、来源和运行映射，不再维护另一套制作教程。

## 当前公开范围

- 大肥鱼项目改编图与署名：[角色说明](CHARACTER_RIGHTS.md)。其他角色完整图、声音与社区原GIF不统一套用大肥鱼许可。
- 教程展示图片：[图片记录](../tutorials/image-sources.json)。候选、定稿、发布后三视图、裁切与本轮重绘分别标明。
- 4个已审核字体文件及许可：[署名表](ATTRIBUTIONS.md)和[字体许可目录](licenses/fonts/)。
- 原歌曲、人声参考、原始混音和部分动图不作为公开下载素材提供。

## 运行工程

没有原媒体也能运行[公开占位演示](../editor/README.md#a公开占位演示无私人素材)，使用程序图形和静音。合法持有原运行文件者，可按同页B路径核对并导入本地忽略目录；正式运行依赖共19项。

原运行清单与新增教程展示目标保存在[asset-manifest.json](asset-manifest.json)，后续三视图索引在[post-freeze-manifest.json](post-freeze-manifest.json)。清单出现不等于文件已经公开，也不表示取得再分发许可。

## 来源与验证

[source-inventory.json](source-inventory.json)记录冻结源文件，[提示词目录](prompts/)保留历史请求与采用状态。[构建与QC](../../../reports/02_build_and_qc.md)记录公开演示和合法本地原媒体的独立重渲染；技术验证不会自动改变素材许可。
