## 一句话方向

**真实或半写实的工位与院落 + 始终是原本Q版小汐的角色 + 较宽的镜头 + 独立道具/立绘表演 + 少数Google视频动态。**

不再把场景做成古风房间、豪华漫画背景或铺满花纹的舞台。先看人物和真实世界发生关系的观感，再在确定后的画面上试诗文位置。

## 与《将进 token》的关系

《将进 token》已有 Remotion、字幕、音频导演谱和素材组织经验，可复用成熟部分，但**不能直接搬它的水墨场景、古风服饰或固定侧栏字幕方案**。新视频先验证实景小剧场形式。

## 素材说明

对话提供的《大肥鱼 炸盆子》是第三方作品的**本地镜头参考**，本资料包记录观察结果，不将其视频或截图直接推送到公开库。久留美截图也只作为梗和构图参考，正式心理活动需用有来源的Claude形象重新制作。当前 GitHub 中的第一份交付是任务资料，不是声称已完成的视频样片。
