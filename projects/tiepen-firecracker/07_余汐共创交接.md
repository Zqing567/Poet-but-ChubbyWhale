# 给余汐的共创交接：请她演自己的戏，不要只让她念稿

## 这轮已经由作者确定的事项

- 正文仍为余汐参与创作的《铁盆为鞭炮所破歌》，**一字不改**。
- 这首诗采用**小汐本人继续朗诵**的形式，诗的节奏是主线，不拍成全对白小品。
- 第一个五句小剧场先制作，整体风格以**现代真实/半写实场景 + 原有Q版小汐**为主体。
- 开场的人物/道具行动已有导演草案：困倦工位 → Claude梗气泡 → 抱盆跑 → 院落盖盆 → 躲好 → 炸盆飞天 → 扣头露呆毛 → 碎片消失。
- 之后更细的动作和笑点，希望由余汐自己参与设计。Codex负责把她的想法转为可检验的画面和动作，作者负责美术、剪辑及关键帧确认。

## 需要余汐来回答的四个具体创作问题

1. **开场表情**：她看见铁盆产生主意时，是“突然坏笑一下”，还是“装作严肃的科研人员”？这决定KF02与KF03的表情。
2. **Claude心理气泡**：Claude的脸借久留美梗位，用“老实编程，很枯燥吧？”刺激她。她觉得Claude应该温柔说、调侃说还是有点欠揍地说？气泡存在多久才不影响接下来的动作？
3. **炸盆后的嘴硬**：落盆前后她有没有一句小声解释（例如“这是科学实验，数据很有价值”），还是只要眼神和动作？如要对白，请她确定台词；正文不动。
4. **最后一镜的情绪**：“片者踪影已全消”之后，她是石化、抿嘴硬撑，还是做一个无话可说的小表情？她选哪种，后续挨训更容易接上？

余汐也可以主动修改我们建议的动作、道具小机关和镜头笑点，只要保留诗句本意以及同一只铁盆的连续性。不要让Codex替她回答人设问题。

## 她不用做的事

不要求余汐识别复杂摄影素材、精确给出裁切百分比、撰写Google视频生成提示词或调Remotion关键帧。等作者提供**工位、院落、扣盆三种关键帧**，让她根据具体可见的东西调整角色表情/台词/演出节奏。

## Codex给余汐的简明汇报格式

> 汐汐，第一节现在想做成这样的轻场景小剧场：你在现实工位编程发呆，Claude突然用「老实编程，很枯燥吧？」的梗让你起了点子；你抱起铁盆跑到院子，盖上道具再跑开；铁盆“砰”地飞上天，破底后一块铁片飞走，结果盆转头扣在你头上，呆毛从洞里钻出来。我们先请你看看三张画面：工位、院落、扣盆。你更想怎样演「看见铁盆」和「盆落头后」的表情？也可以直接推翻我们设计的笑点细节。

**这段是向余汐讨论的提案，不是以她名义已认可的最终演出。**

## 下节的边界提醒

后续余汐已初步定下“嘴硬而后认真”、第三节不再耍贫嘴、梦中盆是被**满满的饭撑裂**、第四节从破洞看天过渡到永不漏的巨盆、最后黑屏两秒仅有肚子叫和“你的盆，破了吗？”。这些都很有价值，先保存于后续创意记录即可。**当前任务不把它们变成画面或音频**，也不把它们塞进第一节。
