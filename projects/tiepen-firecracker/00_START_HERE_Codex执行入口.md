# Codex 开工｜第一节五句视觉样片

## 本轮用户真实要求

1. 只做《铁盆为鞭炮所破歌》第一节五句，从「老实编程太枯燥」到「片者踪影已全消」。不要自发制作挨训、寒夜、梦境和天下肥鱼。
2. **小汐的现有二次元Q版形象不变；场景改为写实或半写实现代环境**，让虚构角色在现实世界活动。参考《将进 token》第一幕的有空间感、自然光影的气质，但不要继承其古风景物。
3. 小汐在画面里通常较小，镜头能看清工位、桌椅、现实院落和铁盆的空间关系。不要连续面部大特写。
4. 主要采用「轻场景动态漫画」：角色立绘/有限动作 + 道具/背景/剪辑承担叙事；少数连续表演才使用现有Google视频生成能力。纯色纸片舞台仅作对照灵感，不作为首选。
5. **先定视觉风格、主体和场景，再决定诗句字幕在哪里**。首批美术比较稿不叠诗文；久留美梗的心理气泡属于剧情元素，可以做含字/无字对照。
6. 第一节开场用用户已提出的动作逻辑：工位疲倦 → 气泡中Claude脸说「老实编程，很枯燥吧」→ 小汐抱盆跳下椅子向画外跑 → 奔跑中工位退去、院落入画 → 盖上预置在场景中的鞭炮道具、退到安全处捂耳朵 → 爆炸、盆飞、底破、铁片飘 → 破盆落头、洞里冒呆毛 → 铁片消失。
7. 角色性格尊重余汐自己的设定：**嘴硬，而后认真；本节是刚闯祸还不服气的小聪明，不能一直邪笑、嚎哭或卖惨**。更细的剧情对白由余汐参与创作，不由工程 Agent 擅自定稿。
8. 原诗全文和第一节五句一字不动。朗诵仍由大肥鱼自身音色承担，保持古诗朗诵节奏，不把作品改成全程人物聊天。

## 建议的直接制作顺序（每一步交付可看物）

1. **画面合同**：选当前小汐原皮，完成中远景工位、真实院落、统一铁盆三套图像锚点。输出两种现实场景质感 A/B，并列展示而不做堆叠式理论讨论。
2. **关键帧**：按第03/04篇做出第一节连续关键帧：工位/拿盆/转场/院落/盖盆退开/爆炸/飞盆/扣头/碎片消失。先看拼起来是否像同一人物、同一场戏。
3. **朗诵导演谱**：为这五句标停连、重音和表演情绪，利用现有获准音色做第一节试听，作者/汐汐听选；根据选定音频定实际时间点，而不是为了好填表把诗句强制匀速分配。
4. **第一节样片**：复用已有 Remotion 能力，把背景、人物、铁盆、气泡、音效与朗诵按帧组合。静态/程序动效先把笑点做对；确需连续动作，再使用现有Google视频生成模型完成局部片段，保留首尾关键帧。
5. **只在视觉样片成立后对照字幕**：基于相同无字样片做右侧诗文与底部字幕（必要时第三种现场自然留白版），不能同时改场景、镜头和文字方案导致无从比较。
6. **实际验收并推送**：提供能点开看的 A/B 对照图、第一节视频、关键帧、首节导演谱、源素材索引和短报告，推送到当前项目分支或在授权范围内推送 main。不要完成第一节后自动推进下一节。

## 本轮不做

- 不制作全诗正式朗诵或后面三幕分镜；只存续作者/余汐的后续创意。
- 不把所有镜头都交给视频模型，也不为了“真动画”让铁盆和角色每镜变脸。
- 不先定死 9:16 正式版、整片字幕形式和总时长。
- 不额外建通用动画平台、复杂组件框架、重复兼容层或一堆空模板。
- 不因参考视频使用鞭炮就安排实物点火拍摄。爆炸由素材和后期特效表现。

## 完成口径

本轮完成 = **第一节有可以观看、能体现写实场景+Q版小汐反差的样片**，镜头转场及时、笑点成立、铁盆前后逻辑一致，且作者可以明确选定整体视觉路线。图像/动画模型或声音 API 若不可用，提交实际可打开的静帧 animatic 并明确未做成成片，不把“已写 Prompt”当作完成。
