# 第一节动画逻辑预览

这是第一节五句的**动作与镜头示意**，用于检查因果、位置和剪辑。画面中的简笔图形只表示走位和道具状态；它们不是角色设计或正式镜头。没有诗句字幕、正式朗诵和音效。21 秒只是便于检查的临时节拍，最终切点须根据选定的朗诵调整。

在本目录运行 `npm ci`，再运行 `npm run studio`，打开终端显示的本地地址并选择 `Tiepen-Logic`，可播放和拖动时间线。

也可直接观看 [21 秒逻辑示意视频](../previews/first-stanza-logic-animatic.mp4)。视频为静默 H.264，1280×720、30 帧/秒。

| 临时时间 | 动作与衔接 |
| --- | --- |
| 0–4 秒 | 工位疲倦；Claude 心理气泡出现；注意到铁盆。 |
| 4–6.5 秒 | 拿走同一只盆，向右跑出，下一镜从左进入院落。 |
| 6.5–11 秒 | 把盆盖在已放置的鞭炮上，退到木箱后捂耳朵。 |
| 11–12.6 秒 | 爆响，盆向上飞并破底，一片铁片分离。 |
| 12.6–15 秒 | 切天空：破盆继续飞，铁片向另一方向离开。 |
| 15–19 秒 | 回院落；小汐走出，头顶先有阴影，破盆落头，呆毛穿过破口。 |
| 19–21 秒 | 铁片已经消失，小汐停住；第一节结束。 |

后续制作正式镜头时，以作者最终确认的小汐形象、Claude 参考和同一只盆的状态为约束，人物与场景一起生成，再按选定朗诵调整节奏。当前预览不能证明正式画面的动作、接触、视觉一致性或配音节奏已经通过。
