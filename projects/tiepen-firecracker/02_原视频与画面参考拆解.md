# 本地参考拆解：真实院落为什么比古风动漫场景更适合这次视频

## 参考素材清单（作者在对话上传，不保证已存在于Codex本地）

- 视频文件名：《大肥鱼 炸盆子》.mp4（当前对话附件显示文件名“大肥鱼 炸盆子.mp4”）；读取结果约 **15.10秒、1440×1080、30fps、4:3**，有现场环境与声音。原视频为第三方参考，不迁入公开仓库，不照搬水印。
- 梗图：作者发的一张粉发近景截图，角色在说「老实赚钱，很枯燥吧」，来自久留美梗。作者的创作方向是**把这个表情/梗位的角色换为已确认的Claude形象，把话改为「老实编程，很枯燥吧」**，作为小汐的心理气泡，而不是把原截图原封不动贴进去。
- 《将进 token》第一幕：参考镜头层次、明暗与大气空间感，不继承它的古风水墨场景与古装人物。
- 小汐已认可的角色形象图：身份锚点必须由作者当前角色图确定。旧诗人立绘不等于这部视频的角色服装合同。
- 上一次聊天中生成的七张小剧场设计图：只可提取“表情、道具、关键事件”的创意；大部分把现代小剧场错做了古风梦幻书房，**不可把它们当这轮要达成的美术参考**。

## 视频实际按时间抽看的动作（供制作时快速对照）

| 原片相对时间（约） | 看到了什么 | 我们要借鉴的镜头方法 |
| --- | --- | --- |
| 0–1.5s | 现实院落固定全景，小小的蓝发卡通大肥鱼出现在地上，画面有多个旧铁盆、墙面树影、旧木箱与扫帚 | 镜头远、真实空间给足，小鱼融进院子，先交代道具位置 |
| 1.5–3.0s | 小鱼走向中部的金属盆，将一个盆罩到地面物件上 | 只演“盖盆”这个核心动作，不拖长准备过程 |
| 3.0–5.8s | 小鱼往木箱一侧退开，最终躲到箱后 | 以横向移动+遮挡代替复杂人物连续动画 |
| 6.0–7.3s | 地面出现爆响后的烟尘/灰烟，盒子后的小鱼露出一点边缘 | 爆炸靠音效与云烟，不必拍实物危险操作 |
| 8.0–10.2s | 插入蓝天镜头，铁盆从画面中间向上飞，高度以单一物体变化表达 | **背景单纯 + 一只盆飞天**，不需要大规模流体模拟 |
| 11.0–14.3s | 回到院落，小鱼走出，盆随后落到头上形成盆帽 | 第二个笑点来自意外回头，不是另一场爆炸 |

> 观察说明：原片不必然明确展示“盆底破洞、铁片飞散、呆毛从洞露出”的完整细节。本次诗句要求这些内容，需由新视频新增关键帧，不要声称原片已经拍出了它们。时间码是参考片本身，不是新朗诵的正式秒数。

## 视频里最值得学的四件事

1. **现实光影**：自然地面、旧木箱、日照投影已经足够讲清楚环境。现代普通物件比花哨画面更有反差。
2. **角色不必成为画面正中央**：4:3 原片多数时间卡通鱼非常小，它与几个现实铁盆、木箱的尺度反差，就是笑点之一。
3. **核心动作可跳切**：“站立 → 盖盆 → 跑开 → 爆炸 → 飞盆 → 扣头”依次传达，观众可以补全物理过程。
4. **固定机位带来可信的意外感**：木箱后只露出小鱼一点点；突然爆炸以后，镜头先看天，再切回等待落盆，戏剧节奏清楚。

## 借鉴边界

**学习结构，不照抄每个像素。** 可以将院落替换成更合适的现代空地、把铁盆形态做得更醒目；但保留“现实背景 + 2D小角色 + 道具意外”的风格。原视频及粉发梗图是第三方素材，如要制作公开二创图，应使用获得授权的元素或自行重绘梗位，而不是把完整原帧与水印推送到公开库。

## 特别针对“Claude心理活动气泡”

设计一个占画面一角的短气泡，画面内容是Claude的已认可拟人形象，神情可以借鉴粉发角色的微笑与近脸构图；在气泡上或内加文案：

**「老实编程，很枯燥吧？」**

只让它在“老实编程太枯燥”附近出现一瞬，与小汐突然注意到铁盆的视线相呼应。气泡是心理活动，不是诗句字幕，不应该持续挡住后续奔跑和爆炸。中文文字后期用 Remotion 绘制，避免直接生图出现错字。若Claude的最终角色脸未确认，先给气泡留一张身份占位，再请作者/汐汐挑。
